### Slide 25
Trichromacy
n In color matching experiments, most people can
match any given light with three primaries.
n Primaries must be independent.
n For the same light and same primaries, most
people select the same weights.
n Exception: color blindness
n Trichromatic color theory
n Three numbers seem to be sufficient for encoding
color.
n Dates back to 18th century (Thomas Young).
Adapted from W. Freeman
NPTEL

### Slide 26
Grassman’s Laws
n Color matching appears to be linear.
n If two test lights can be matched with the same set
of weights, then they match each other:
n If  A = u1P1 + u2P2 + u3P3 and B = u1P1 + u2P2 + u3P3. Then A = B.
n If we mix two test lights, then mixing the matches
will match the result:
n If A = u1P1 + u2P2 + u3P3 and B = v1P1 + v2P2 + v3P3.
Then A+B = (u1+v1) P1 + (u2+v2) P2 + (u3+v3) P3.
n If we scale the test light, then the matches get
scaled by the same amount:
n If A = u1P1 + u2P2 + u3P3, then kA = (ku1) P1 + (ku2) P2 + (ku3) P3.
Adapted from W. Freeman
NPTEL

### Slide 68
Opponent Color Processing
n The color opponent process: A theory proposed
on perception of color by processing signals from
cones and rods in an antagonistic manner.
n Overlapping spectral zone of  three types of cones
(L for long, M for medium and S for short).
The visual system considered to  record differences
between the responses of cones, rather than each
type of cone's individual response.
n People don’t perceive reddish-greens, or bluish-yellows.
