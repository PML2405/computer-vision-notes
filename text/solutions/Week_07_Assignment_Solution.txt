QUESTION 7:
Type: MCQ
Which of the following statements about a KD-tree is correct?
a) A KD-tree always splits the data using the same coordinate axis at every level.
b) In a KD-tree, each internal node partitions the space into two regions using one
coordinate axis.
c) A KD-tree guarantees perfectly balanced partitions irrespective of insertion order.
d) KD-trees can only store 2-dimensional points.
Correct Answer: b)
Detailed Solution:
A K-dimensional tree is a binary search tree used for organizing points in a
multi-dimensional space. Each node divides the space into two half-spaces:
Left subtree: points smaller along the active axis
Right subtree: points greater along the active axis
Therefore, option b) is correct.
a) Incorrect: KD-trees alternate splitting axes rather than always using the same axis.
c) Incorrect: The balance of a KD-tree depends on insertion order and construction
method.
d) Incorrect: KD-trees work for any dimension k, not only 2D.

Consider points in 2D plane (5,5), (12, 10), (8, 1), (2, 8), (10, 14). After building a 2D binary
search tree following the given order starting with an X-split, which point becomes the left
child of the root node?
a) (12,10)
b) (2,8)
c) (8,1)
d) (10,14)
Correct Answer: b
Detailed Solution: A 2D KD-tree is constructed by alternating split axes:
X →Y →X →Y →· · ·
Root node uses an X-split. Step 1: Insert (5,5). This becomes the root.
Step 2: Insert (12,10). Compare x-coordinate with root. Hence, it goes to the right of (5, 5).
Step 3: Insert (8,1). Compare with root using x-split. Move right to (12, 10). Now compare
using y-split. Hence, (8, 1) becomes the left child of (12, 10).
Step 4: Insert (2,8). Compare with root using x-split. Hence, (2, 8) becomes the left child of
the root.
Step 5: Insert (10,14). Compare with root using x-split. Move right to (12, 10). Now compare
using y-split. (10, 14) becomes the right child of (12, 10).
