QUESTION 1:
Type: MCQ
In binary (Gray-code) structured-light encoding, n patterns are projected. How many distinct
stripes can be uniquely encoded?
a) n
b) 2n
c) 2n
d) n2
Correct Answer: c
Solution: Each stripe receives a unique n-bit binary codeword from the n projected
black-and-white patterns. With n bits there are exactly 2n distinct codewords, so 2n stripes
can be encoded.
QUESTION 2:
Type: MCQ
In a 3-pattern binary structured-light system, what is the 3-bit Gray code assigned to stripe
number 5 (0-indexed)?
a) 101
b) 111
c) 110
d) 100
Correct Answer: b
Solution: The Gray code of an integer n is obtained by g = n ⊕(n ≫1) (XOR with its own
right-shift by 1):
510 = 1012,
g = 101 ⊕010 = 1112.
QUESTION 3:
Type: MCQ
Which of the following statements about the Microsoft Kinect (first generation) sensor is/are
correct?
a) It projects an infrared laser speckle pattern onto the scene.
b) Points at greater depth appear more defocused / blurry in the IR image.
c) It operates on the principle of structured light triangulation.
d) All of the above.
Correct Answer: d
Solution: The first-generation Kinect uses an infrared (IR) laser diode that projects a
pseudo-random speckle pattern. A separate IR camera observes how the speckle deforms
with depth (structured-light triangulation). Because the IR camera has a fixed focus, objects
at depths further from the focal plane produce blurrier speckle spots. All three statements are
therefore true.
QUESTION 4:
Type:MCQ
Consider the surface z = xy parametrised as X(u, v) = (u, v, uv). Which of the following is
the first fundamental form?
a) (1 + v2) du2 + 2uv du dv + (1 + u2) dv2
b) (1 + v) du2 + uv du dv + (1 + u) dv2
c) (1 + v3) du2 + 2uv du dv + (1 + u3) dv2
d) (1 + v2) du2 + uv du dv + (1 + u2) dv2
Correct Answer: a
Detailed Solution: Compute the partial derivatives:
Xu = (1, 0, v),
Xv = (0, 1, u).
First fundamental form coefficients:
E = Xu · Xu = 1 + v2,
F = Xu · Xv = uv,
G = Xv · Xv = 1 + u2.
The first fundamental form is:
ds2 = E du2 + 2F du dv + G dv2 = (1 + v2) du2 + 2uv du dv + (1 + u2) dv2.
QUESTION 5:
Type: MCQ
For the surface X(u, v) = (u, v2, uv), compute the first fundamental form coefficients E, F, G
at the point (u, v) = (1, 2).
a) E = 5, F = 2, G = 17
b) E = 5, F = 4, G = 9
c) E = 2, F = 4, G = 17
d) E = 5, F = 2, G = 5
Correct Answer: a
Detailed Solution:
Xu = (1, 0, v),
Xv = (0, 2v, u).
At (u, v) = (1, 2): Xu = (1, 0, 2), Xv = (0, 4, 1).
E = Xu · Xu = 1 + 0 + 4 = 5,
F = Xu · Xv = 0 + 0 + 2 = 2,
G = Xv · Xv = 0 + 16 + 1 = 17.
QUESTION 6:
Type: MCQ
Consider the 2D parametric curve x(t) = t2 + t, y(t) = 2t −1. Compute the tangent vector
(x′(t), y′(t)) at t = 1.
a) (2, 2)
b) (3, 2)
c) (2, 4)
d) (1, 2)
Correct Answer: b
Detailed Solution:
Differentiate each component:
x′(t) = 2t + 1,
y′(t) = 2.
At t = 1:
x′(1) = 2(1) + 1 = 3,
y′(1) = 2.
Tangent vector = (3, 2).

QUESTION 9:
Type: MCQ
A surface patch is measured at a point P and found to have principal curvatures κ1 = +3.2
and κ2 = −1.7. Which of the following correctly classifies the surface at P and gives the sign
of its Gaussian curvature K?
a) Pit surface;
K > 0
b) Saddle surface;
K < 0
c) Ridge surface;
K = 0
d) Flat surface;
K = 0
Correct Answer: b
Detailed Solution: the Gaussian curvature is the product of the two principal curvatures:
K = κ1 · κ2.
Since κ1 and κ2 have opposite signs,
K = (+3.2)(−1.7) = −5.44 < 0.
QUESTION 10:
Type: MCQ
Which of the following statements about edge detection in range images is correct?
a) Step edges are detected from zero crossings of Gaussian curvature.
b) Roof edges are detected from zero crossings of Gaussian curvature.
c) Roof edge points are detected by extrema of the dominant principal curvature along its
corresponding direction.
d) Step edge points are detected by extrema of the dominant principal curvature along its
corresponding direction.
Correct Answer: c
Detailed Solution: In range image edge detection, step edges arise at depth discontinuities
(jumps in the range value) and are detected by zero crossings of Gaussian curvature (not by
extrema). Roof edges arise where two surfaces meet at a dihedral angle and are detected by
extrema of the dominant principal curvature along the direction corresponding to that
curvature.
