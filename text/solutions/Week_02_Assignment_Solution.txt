QUESTION 4:
Type: MSQ
Which of the following properties are true for a homography?
a) it transforms point in real 𝑅2 space to projective 𝑃2 space.
b) three points lie on the same line if and only if their homographic transforms lie on the
same line.
c) minimum 4 point correspondences needed to compute homography.
d) only in the form of singular 3 × 3 matrix.
Correct Answer: b), c)
Detailed Solution:
a) Homography is a projective transformation, i.e. 𝑃2 →𝑃2. It preserves collinearity, and is
always in a linear form. d) A homography matrix must be non-singular (invertible).
