QUESTION 1:
Type: MSQ
Which of the following statements are true for Pooling?
a) It accumulates training data into a central buffer to optimize the gradient descent
optimization process.
b) It provides translational invariance, allowing the network to detect features even if they
are shifted, rotated, or slightly distorted.
c) It reduces the spatial dimensions (width and height) of the feature maps, thereby
decreasing the number of parameters and computational complexity.
d) It selectively extracts dominant features (like maximum or average values) while
discarding less prominent activations.
Correct Answer: b), c) and d)
Detailed Solution:
a) False. Pooling has nothing to do with pooling training data together. It operates strictly on
the internal feature maps (activations) layer-by-layer within the network.

QUESTION 3:
Type: Numeric
An autonomous driving system’s object recognition model classifies a detected obstacle into
one of four classes: Pedestrian, Bicycle, Car, or Truck. For a specific sample, the model
outputs the softmax predictions [0.08, 0.12, 0.65, 0.15]. Calculate the cross-entropy loss for
this sample (using the natural logarithm) if the actual ground truth object is a Truck,
represented by the true labels [0, 0, 0, 1]. Round off the answer to 4 places of decimals.
Correct Answer: 1.8971
Detailed Solution: L = −P y · log(p) where y is the true label and p is the predicted
probability. In this case, we calculate it as: L = −[1 · log(0.15)] = 1.8971
QUESTION 4:
Type: MSQ
Which of the following statements are true for Batch normalisation?
a) It returns the normalised mean and standard deviation of the weights.
b) It normalizes the intermediate layer activations across a mini-batch during training.
c) It is a very efficient backpropagation technique.
d) It allows using higher learning rate.
Correct Answer: b), d)
Detailed Solution:
Batch normalization calculates the mean and variance for each mini-batch to stabilize the
feature distributions and mitigate internal covariate shift. By preventing gradients from
exploding or vanishing across layers, it safely allows the network to train with much larger
learning rates.

QUESTION 10:
Type:Numeric
In an object detection problem, the time taken to generate all proposals is 0.75. There are 4
number of proposals generated. What is the inference time of a Faster RCNN if the
convolution time and the time taken by the fully connected layer are 2.25 and 1.75,
respectively? Round off the answer to 2 places of decimals.
Correct Answer: 9.25
Detailed Solution: Inference time of Faster RCNN = 1× ConvTime + NumProp × fcTime =
2.25 + 4 × 1.75 = 9.25,
where,
NumProp = number of proposals generated
ConvTime = convolution time
fcTime = time taken by the fully connected layer.
