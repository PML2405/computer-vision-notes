QUESTION 1:
Type: MSQ
Which of the following statements are true for an Artificial Neural Network?
a) A single neuron with two inputs and the signum activation function can implement an
AND gate.
b) A single neuron with two inputs and the signum activation function can implement an
XOR gate.
c) A single neuron with multiple inputs and the signum activation function acts as a linear
discriminator in a multidimensional feature space for two linearly separable classes.
d) A single neuron with multiple inputs and the sigmoid activation function computes
posterior of a class for a two-class classification problem in a multidimensional feature
space.
Correct Answer: a, c, d
Detailed Solution:
a) True. Because an AND gate is a linearly separable function, a single neuron
(perceptron) can easily find a decision boundary line that separates the output 1 from
the output −1 (or 0).
b) False. Because an XOR gate is not linearly separable, meaning a single straight line
cannot separate the true outputs from the false outputs in a 2D plane; it requires a
multi-layer network.
c) True. Because the decision boundary of a single neuron with a signum activation
function is defined by a linear combination of its inputs (𝑤𝑇𝑥+ 𝑏= 0), which forms a
hyperplane that splits the multidimensional space into two classes.
d) True. Because the sigmoid function mathematically models the posterior probability
𝑃(Class 1 | 𝑥) under the assumption that the class-conditional distributions are normal
with equal covariance matrices.

algorithm. After first iteration clusters, C1, C2, C3 has following observations:
C1: (2,2), (4,4), (6,6)
C2: (0,4), (4,0)

a) C1: (4,4), C2: (2,2), C3: (7,7)

QUESTION 8:
Type: MCQ
An optimization algorithm is updating a 197-dimensional parametric space to train a
single-hidden-layer feedforward neural network. If the input layer accepts a 10-dimensional
feature vector and the output layer yields a 2-dimensional vector, determine the number of
neurons present in the hidden layer.
a) 12
b) 15
c) 20
d) 25
Correct Answer: b) 15
Detailed Solution:
Let ℎbe the number of neurons in the hidden layer. The total number of parameters (weights
and biases) in a network with a single hidden layer can be mathematically expressed by the
formula: Total Parameters = (𝑑𝑖𝑛+ 1) · ℎ+ (ℎ+ 1) · 𝑑𝑜𝑢𝑡
197 = (10 + 1) · ℎ+ (ℎ+ 1) · 2
197 = 11ℎ+ 2ℎ+ 2
197 = 13ℎ+ 2
195 = 13ℎ
ℎ= 195
13 = 15
Thus, the hidden layer contains exactly 15 neurons.
