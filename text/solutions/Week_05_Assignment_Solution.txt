QUESTION 10:
Type: MSQ
Consider a stereo setup with camera matrices P = K[I|0] and P′ = K[I|t], where translation is
only along the x-axis and there is no rotation between the cameras. Which of the following
statements are correct?
(a) The fundamental matrix must always be a full rank matrix.
(b) The epipolar lines in the two images are parallel.
(c) The essential matrix has rank 3.
(d) The disparity between corresponding image points can be used to estimate depth.
Correct Answer: (b), (d)
Detailed Solution:
For pure translation along x-axis with no rotation, the epipolar lines become parallel
horizontal lines. Hence statement (b) is correct.
Fundamental matrix always has rank 2, not full rank. Hence statement (a) is incorrect.
Essential matrix also has rank 2 with one singular value equal to zero. Hence statement (c) is
incorrect.
Depth can be estimated using disparity relation
Z = f B
d
where f is focal length, B is baseline, and d is disparity. Hence statement (d) is correct.
