QUESTION 7:
Type: MSQ
Which of the following are true about sparse representation and dictionaries?
a) A dictionary can be over-complete, meaning it has more atoms than the signal dimension.
b) OMP is a greedy algorithm that selects one atom per iteration.
c) Sparse representation requires all atoms of the dictionary to be used.
d) Basis Pursuit replaces the ℓ0 minimisation with an ℓ1 minimisation for tractability.
Correct Answer: a, b, d
Detailed Solution: Over-complete dictionaries have more columns than rows, providing
richer representational capacity. OMP greedily selects the atom most correlated with the
current residual at each iteration. Sparse representation by definition uses only a small subset
of the dictionary atoms; the representation coefficient vector has few non-zero entries. The ℓ0
norm (count of non-zeros) minimisation is NP-hard; Basis Pursuit relaxes it to ℓ1
minimisation, which is convex.

QUESTION 9:
Type: MCQ
Which of the following correctly identifies how K-SVD generalises K-means clustering?
a) K-SVD uses ℓ2 norm for the reconstruction error, while K-means uses ℓ1 norm.
b) In K-means each data point is represented by exactly one cluster centre; in K-SVD each
signal can be represented by a sparse combination of multiple dictionary atoms.
c) K-SVD initialises its dictionary randomly, whereas K-means always uses a fixed
initialisation.
d) K-means allows each data point to be represented by multiple cluster centres; K-SVD
restricts representation to one atom.
Correct Answer: b
Detailed Solution: K-means assigns each point to a single centroid (sparsity k = 1, binary
coefficients). K-SVD generalises this by allowing each signal to be reconstructed from a
sparse linear combination of k > 1 dictionary atoms with real-valued coefficients.
